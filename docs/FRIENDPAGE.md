# Friend page: шапка

Экран «Страница друга» собирается из `template-sources/friendpage/` в
`templates/friendpage.bundle.html` скриптом `npm run bundle:friendpage`.

Скрипт собирает два экрана:

| исходник | бандл | режим |
|---|---|---|
| `template-sources/friendpage/friendpage.html` | `templates/friendpage.bundle.html` | ПК (веб-версия), скрипты вырезаются |
| `template-sources/friendpage-mobile/friendpage-mobile.html` | `templates/friendpage-mobile.bundle.html` | телефон, скрипт `renderSteamFriend` остаётся |

Выбор режима — первым шагом после кнопки: `🖥 ПК (веб-версия)` или `📱 Телефон`. Дальше поток
одинаковый: ссылка → скриншот → «Добавить код друга» → второй скриншот с кодом.

Важно: `scripts/` и `template-sources/` исключены в `.dockerignore`, поэтому сборщик бандла в образ не
попадает и в `Dockerfile` шага сборки нет — образ берёт **закоммиченный** `templates/friendpage.bundle.html`.
После правок в `template-sources` бандл надо пересобрать и закоммитить вместе с ними:

```bash
npm run bundle:friendpage
git add template-sources templates/friendpage.bundle.html
```

## Что добавлено

Сохранённая страница была в «мобильной» разметке Steam: узкая полоса с гамбургером и логотипом, без
верхнего меню и без правого блока. Сверху вставлена настоящая шапка Steam — та же, что на `/auth`
из панели (`ch/v2/eu/auth/view.html`), с нашими правками колокола.

Итог: логотип, `STORE / COMMUNITY / <ник> / CHAT / SUPPORT`, справа серая кнопка `Install Steam`,
плашка с колоколом, ник со стрелкой, баланс `$3.87` под ником и аватар 32×32.

Активная вкладка — вкладка ника (`supernav_active` на `.menuitem.username`), не `COMMUNITY`: страница
это профиль, а не лента сообщества.

## Как вставлено

Блок `<div role="banner" id="global_header">…</div>` вырезан из `view.html` целиком и вставлен в
`friendpage.html` сразу после `<div class="responsive_page_content">`. Стили колокола и плашки
(`#green_envelope_menu_root`, `.header_notification_link`) добавлены в `<head>` перед `</head>`.

Плейсхолдеры панели заменены на плейсхолдеры бота:

| было (страница `/auth`) | стало (страница друга) |
|---|---|
| `{{NICK}}` | `{{PROFILE_NAME}}` |
| `{{AVATAR}}` | `{{AVATAR_URL}}` |
| `{{ACCOUNT}}` | `{{PROFILE_NAME}}` |
| `https://steamcommunity.com/profiles/{{PROFILE_ID}}/` | `{{PROFILE_URL}}` |

Логотип шапки ссылался на `/auth/cdn/…svg` — путь есть только на панели. Файл скопирован в
`template-sources/friendpage/friendpage_files/logo_steam.svg`, ссылка стала относительной, бандлер
вшивает его как data URI вместе с остальными ассетами (21 штука).

## Колокол

На этой странице лежит `greenenvelope.css` — стили React-кнопки уведомлений, и они позиционируют иконку
сами, из-за чего колокол уезжал из плашки. Поэтому плашка нарисована на самом `#header_notification_area`
(46×24, `rgba(103, 112, 123, .2)`), обёртка `[data-featuretarget="green-envelope"]` растянута на неё
флексом, внутренний `<div>` получил `display: contents`, а сама кнопка — `15×15` с `!important` по
геометрии. Без этого набора правок иконка встаёт по левому краю плашки.

## Баланс

`#header_wallet_ctn` заполнен текстом `$3.87` и спозиционирован под ником:

```css
#global_actions #global_action_menu { position: relative; }
#header_wallet_ctn { position: absolute; right: 0; top: 100%; margin-top: 3px; font-size: 11px; color: #b8b6b4; }
```

Сумма в выпадающем меню аккаунта тоже переведена с тенге на `$3.87` — раньше там стояло `2 671,18₸`.

## Отступы справа

Между `Install Steam` и плашкой колокола ровно **7 px** по закрашенным краям.

Почему раньше было 23: меню было инлайн-блоком, и пробел между `</a>` и `<div id="…">` в разметке
рисовался как отдельный зазор, плюс собственный `margin-inline-end: 3px` у кнопки, плюс `margin-left: 17px`
у плашки. Меню переведено на флекс — пробел исчез; маргин кнопки обнулён:

```css
#global_header #global_action_menu { display: flex !important; align-items: center !important; }
#global_header .header_installsteam_btn { margin: 0 !important; }
#header_notification_area { margin: 0 3px 0 7px; }
```

Невидимой части у кнопки нет: `a.header_installsteam_btn` — инлайн-блок без паддингов, его ширина
равна ширине серой заливки (`.header_installsteam_btn_content`), а хвостовой пробел внутри ссылки
браузер отбрасывает. Проверено сканом строки по пикселям: `…-1204` заливка, `1205-1211` зазор 7 px,
`1212-…` плашка.

По вертикали обе коробки — 24 px: у кнопки она была 21 px (Steam ставит её инлайн-блоком на строку
24 px, и на флекс-ряду разница вылезала как смещение на полтора пикселя), поэтому высота выровнена
явно. Скан по колонкам: `install y 5..28` и `bell y 5..28`.

## Телефонный вариант

Отдельный шаблон `friendpage-mobile.bundle.html`: рамка телефона 875×1798, фон картинкой, поверх —
аватар, ник, свой код, введённый код друга и ссылка приглашения. Данные передаются не плейсхолдерами, а
функцией:

```js
window.renderSteamFriend({
  user_pic, friend_code, invite_link, own_code, profile_name
});
```

`profile_name` в исходном шаблоне не было: имя было вшито в фон. Добавлена пара `#name-cover` +
`#profile-name` — плашка цвета полосы (`#28405f`) закрывает старое имя, а поверх рисуется ник со
страницы. Координаты подобраны по рендеру: имя занимало `x 234..532, y 211..256`.

Скриншот берётся с элемента `#frame`, вьюпорт выставляется 875×1798, иначе страница масштабирует рамку
и картинка мылится.

## Проверка

Локальный рендер бандла с подставленными ником и аватаром: шапка на месте, меню и правый блок как на
образце, контент «Add a Friend» не съехал.

## Функционал

Не менялся: те же плейсхолдеры, тот же ввод кода друга, та же кнопка `COPY` и та же ссылка на Quick
Invite. Шапка — только разметка и стили.

## Аватар

Аватар приходит из `<img>` внутри шаблона, а картинка — с внешнего CDN Steam. Два места, где это ломалось:

1. **Не дождались загрузки.** `renderSteamFriend` выставляет `src` сразу, а снимок делался через один
   `requestAnimationFrame` — картинка не успевала приехать, и в кадр попадала дефолтная аватарка,
   запечённая в шаблоне. Внешне: ник и ссылка меняются, аватар — нет.
2. **Зависимость от CDN.** Если из контейнера `avatars.fastly.steamstatic.com` не открывается, `<img>`
   остаётся пустым и под ним снова видна та же дефолтная картинка.

Лечение в `src/bot.js`:

- `inlineAvatar(url)` забирает байты аватара на сервере и отдаёт `data:`-URL; кэш на 50 адресов;
  не удалось — возвращается исходный URL, пусть грузит браузер;
- `screenshotPhoneFriend` ждёт `complete` у всех `<img>` перед снимком;
- то же для QR-страницы и экрана ошибки добавления на телефоне.

Проверка: до правки телефонный кадр показывал дефолтную аватарку при верном нике, после — настоящую.
