# Dota2 Code

Раздел в главном меню: `⚔️Dota2 Code` → `🎯Fake Code`, `❓Not Found`, `🚫Not Friends`.

`Fake Code` ничего не рендерит: это готовая картинка `assets/dota_fake_code.png` (диалог «Add Friend» с
уже вписанным `Your Friend ID`), бот отправляет её буфером и возвращает ту же клавиатуру. Файла нет —
отвечает сообщением, а не падает.

Два других экрана — SVG-страницы, а не canvas: фон вшит картинкой, поверх две текстовые строки —
`NOT FOUND` / `NOT FRIENDS` и `<text id="friend-id">`, куда ставится код.

## Поток

| шаг | что происходит |
|---|---|
| кнопка экрана | бот просит `Отправь френд-код друга.` |
| сообщение с кодом | код проверяется (`[A-Za-z0-9_-]{2,32}`), подставляется в `#friend-id` |
| скриншот | `<svg class="profile" viewBox="0 0 1586 992">` снимается целиком, 1586×992 PNG |

Ссылка на фейк здесь не нужна: ни ника, ни аватара в шаблоне нет, только код.

## Как подставляется

```js
await page.setViewportSize({ width: 1586, height: 992 });
await page.evaluate((code) => {
  document.getElementById('friend-id').textContent = code;
}, friendCode);
```

В самих шаблонах есть ещё чтение `?friend_id=` из адреса, но бот открывает страницу через
`setContent`, поэтому query-параметр не используется — текст ставится напрямую после загрузки.

## Файлы

| шаблон | статус-строка |
|---|---|
| `templates/dota_not_found.html` | `NOT FOUND` |
| `templates/dota_not_friends.html` | `NOT FRIENDS` |

Кэш: ключ `шаблон + код`, так что повторный тот же код отдаётся мгновенно.
