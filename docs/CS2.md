# CS2 Code

Раздел в главном меню: `🎮CS2 Code` → `🎯CS2 Fake Code`, `❓CS2 Code Not found`, `⛔CS2 Ban`.

Экраны — не HTML-шаблоны со вставкой плейсхолдеров, а canvas-страницы: внутри лежит фон в base64 и
функция `window.renderProfile(data)`, которая рисует ник, аватар и код. Скриншот берётся с элемента
canvas, поэтому картинка получается ровно в исходном разрешении.

## Поток

| экран | шаги | данные |
|---|---|---|
| CS2 Fake Code | `Отправь ссылку на фэйк` → скриншот | ник + аватар со страницы, код остаётся `ALLGG-ZDZF` |
| CS2 Code Not found | `Отправь ссылку на фэйк` → `Отправь френд-код кита` → скриншот | ник + аватар со страницы, код из сообщения |
| CS2 Ban | заглушка | — |

Ник и аватар достаются тем же парсером, что и «Страница друга»: `.actual_persona_name` и картинка
профиля. Аватар скачивается ботом и передаётся в шаблон как data URL — Steam CDN не отдаёт CORS-заголовки,
и canvas с обычной ссылкой не экспортировался бы.

## Контракт шаблонов

| файл | canvas | параметры `renderProfile()` |
|---|---|---|
| `templates/cs2_wrong_code.html` | `#image`, 1850×1079 | `nickname`, `avatarDataUrl`, `friendCode` |
| `templates/cs2_not_found.html` | `#cs2-image`, 1844×1079 | `nickname`, `avatarDataUrl`, `code` |

Разные имена у кода — не опечатка: так в самих шаблонах. Бот отправляет оба ключа (`friendCode` и
`code`), каждый шаблон берёт свой.

Вьюпорт выставляется равным размеру canvas, иначе страница масштабирует картинку и элементный скриншот
выходит мыльным.

## Ресурсы

Страницы тяжёлые (2,1 и 2,3 МБ) из-за base64-фона, но рендерятся они в одном браузере из пула и
кэшируются по ключу `ссылка + шаблон + код`. Повторный запрос той же пары отдаётся из кэша.

## Шрифты

Оба шаблона умеют принимать лицензированный Stratum2 как data URL (`fontDataUrl` / `stratum2FontDataUrl`).
Бот его пока не передаёт: без него страница использует локальный шрифт, если он есть на машине, иначе
узкий fallback.
