# Ошибка добавления: телефон

В разделе `🫂Ошибка добавления` три варианта:

```
🫂Ошибка добавления
├── Профиль        — модальное окно на веб-странице (как раньше)
├── Френдлинк      — веб-страница с баннером приглашения (как раньше)
├── 📱 Телефон     — новый экран
└── Сменить шаблон
```

## Поток телефона

```
📱 Телефон → «Отправь ссылку на фейк профиля.» → «Отправь френд-код, который не приняли.»
          → скриншот 851×1849
```

Ссылка даёт профиль (ник и аватар), код вводит оператор — он и стоит в поле рядом с карточкой друга,
под которой уже нарисовано `Failed to send invitation, please retry.`

## Шаблон

`templates/steam_friend_invite_phone.html`, 851×1849. Шесть плейсхолдеров в нижнем регистре:

| плейсхолдер | значение |
|---|---|
| `{{user_nick}}`, `{{user_pic}}` | ник и аватар сверху (шапка и профиль) |
| `{{friend_nick}}`, `{{friend_pic}}` | ник и аватар в карточке друга |
| `{{input_code}}` | код в поле ввода |
| `{{invite_link}}` | ссылка в Quick Invite |

Сейчас обе пары берутся с одной и той же страницы: бот знает только профиль по ссылке, а второй
человек (тот, кто «не смог отправить приглашение») ему неизвестен. Если понадобится отдельный ник сверху —
это ещё один шаг ввода и одна строка в подстановке.

Скриншот снимается с `#steam-screen` при вьюпорте 851×1849; перед съёмкой бот ждёт загрузки картинок.

Кэш: ключ — `ссылка + код`.
