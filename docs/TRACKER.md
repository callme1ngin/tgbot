# Трекер

Кнопка `👁 Трекер` в главном меню (и `/tracker`). Пользователь привязывает профили Steam и получает
уведомление, когда человек выходит в сеть, садится за игру, меняет игру или уходит в оффлайн.

## Источник статуса

`ISteamUser/GetPlayerSummaries` — один запрос на 100 id:

```
https://api.steampowered.com/ISteamUser/GetPlayerSummaries/v2/?key=KEY&steamids=7656119…
```

Поля: `personastate` (0 оффлайн, 1 онлайн, 2 занят, 3 отошёл, 4 не беспокоить, 5 торгует, 6 играет),
`gameextrainfo` (название игры), `personaname`, `avatarfull`.

Три состояния, как договорились:

| state | когда |
|---|---|
| `offline` | `personastate = 0` |
| `ingame` | есть `gameextrainfo` |
| `online` | всё остальное |

«Отошёл», «занят», торговля, смена ника и аватарки не порождают уведомлений — они только обновляют
сохранённое имя, которое подставляется в текст следующего уведомления.

Ссылку вида `steamcommunity.com/id/<имя>` разворачивает `ResolveVanityURL` один раз, при привязке.
`/profiles/<id>` и голый SteamID64 принимаются как есть.

## Хранение

`data/tracker.json` на томе `./data:/app/data` (добавлен в `docker-compose.yml`). Без тома состояние
жило бы в слое контейнера и стиралось каждой пересборкой.

```json
{
  "users": {
    "123456789": {
      "notify": true,
      "profiles": {
        "76561199132512593": { "added": 1763700000, "name": "萌妹子", "avatar": "https://…" }
      }
    }
  },
  "state": {
    "76561199132512593": { "status": "ingame", "game": "Dota 2", "checked": 1763700060 }
  }
}
```

`state` общий на профиль: если за человеком следят трое, Steam опрашивается один раз. Запись атомарная
(`tracker.json.tmp` → `rename`), испорченный файл при старте откладывается рядом как
`tracker.json.broken-<время>`, бот поднимается с пустым списком.

## Опрос

Раз в 60 секунд, один таймер, флаг `polling` не даёт циклам наложиться. Id собираются со всех
пользователей, пачки по 100. Если Steam не ответил за 10 секунд или вернул ошибку — цикл логируется,
состояния остаются прежними, следующий цикл пробует снова. Уведомление уходит только при реальной
смене `status`+`game`; первое наблюдение после привязки — это база, а не новость.

## Интерфейс

```
👁 Трекер
├── ➕ Добавить профиль → «Отправь ссылку на профиль Steam или SteamID64.»
│      └── карточка: ник, статус, SteamID → [✅ Следить] [❌ Отмена]
├── 📋 Мои профили → список кнопок со статусом
│      └── карточка профиля → [🔄 Обновить] [🗑 Отписаться] [← Назад]
├── 🔔 Уведомления: вкл/выкл — персональный тумблер
└── Сменить шаблон
```

Лимиты: 10 профилей на пользователя, 500 на всех (`TRACKER_MAX_PER_USER`, `TRACKER_MAX_TOTAL`).
Уведомления приходят в личку тому, кто привязал; заблокировавший бота просто не получает их, ошибка
уходит в лог и не ломает цикл.

## Тексты уведомлений

| переход | текст |
|---|---|
| оффлайн → онлайн | `🟢 <b>ник</b> в сети` |
| онлайн → в игре | `🎮 <b>ник</b> начал играть в <b>Dota 2</b>` |
| игра → другая игра | `🎮 <b>ник</b> теперь играет в <b>CS2</b>` |
| игра → онлайн | `🟢 <b>ник</b> в сети` |
| онлайн/игра → оффлайн | `⚫ <b>ник</b> вышел из сети` |

Если у подписчика к профилю привязана подпись, она добавляется второй строкой — и только у него:

```
🟢 <b>Kit</b> в сети
✏️ кит на верификации
```

Подпись у каждого своя, поэтому текст собирается внутри цикла по подписчикам, а не один на всех.

## Переменные

| ключ | по умолчанию |
|---|---|
| `STEAM_WEB_API_KEY` | — (без ключа трекер выключается, в лог строка) |
| `TRACKER_POLL_MS` | 60000 |
| `TRACKER_MAX_PER_USER` | 10 |
| `TRACKER_MAX_TOTAL` | 500 |
| `TRACKER_COMMENT_LIMIT` | 64 |
| `TRACKER_DATA_DIR` | `./data` (в контейнере `/app/data`) |

## Подпись к профилю

Своя у каждого подписчика: в ленту уведомлений не уходит, в общем статусе профиля не участвует —
просто пометка оператора («кит на верификации», «долг 2 ключа»).

```
📡 Трекер · Kit
🟢 онлайн
✏️ кит на верификации
SteamID: 76561199132512593

[🔄 Обновить] [✏️ Подпись] [🗑 Отписаться] [← Назад]
```

Поток: `✏️ Подпись` → отдельное сообщение «Отправь подпись к профилю, до 64 символов. Пустое
сообщение — стереть.» → оператор отправляет строку → карточка перерисовывается с подписью.

- хранится в `tracker.json` рядом с профилем: `profiles[steamId].comment`;
- сжимается в одну строку, обрезается по `TRACKER_COMMENT_LIMIT`;
- пустая строка удаляет подпись;
- `← Назад` возвращает к карточке, ничего не сохраняя.
