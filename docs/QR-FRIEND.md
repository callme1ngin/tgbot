# Страница друга с QR

Кнопка `📷QR Страница друга` в главном меню. Пользователь присылает ссылку, бот собирает страницу
«Add a Friend» с QR-кодом этой ссылки и отправляет скриншот.

```
📷QR Страница друга → «Отправь ссылку на фейк.» → скриншот 871×1806
```

## QR

Генерируется на сервере пакетом `qrcode` — чистый JS, без нативных зависимостей:

```js
const qrDataUrl = await QRCode.toDataURL(url, { margin: 1, width: 530, errorCorrectionLevel: 'M' });
```

530 px на коробку 265 px в шаблоне: картинка остаётся резкой, если её открыть в полном размере.
Содержимое кода — та самая ссылка, которую прислали, то есть сканирование ведёт на нашу страницу.

## Шаблон

`templates/steam_community_qr.html`, 871×1806, фон картинкой. Четыре плейсхолдера в нижнем регистре,
не такие, как в остальных шаблонах, поэтому подставляются напрямую, а не через общий набор:

| плейсхолдер | значение |
|---|---|
| `{{user_nick}}` | ник со страницы |
| `{{user_pic}}` | аватар со страницы |
| `{{qr_code}}` | data URL сгенерированного QR |
| `{{invite_link}}` | ссылка |

Скриншот снимается с `#capture` при вьюпорте 871×1806; перед съёмкой бот ждёт загрузки картинок,
иначе аватар с CDN успевает не появиться.

Кэш: ключ — ссылка, повторный запрос той же страницы отдаётся мгновенно.
